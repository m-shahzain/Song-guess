# Bollywood Beat

A fast-paced Bollywood music guessing game where players listen to a 5-second audio clip and try to identify the correct song from multiple choices.

This project is built with React, TypeScript, and Vite, and uses the Apple iTunes Search API to fetch music metadata and preview clips.

## Features

- 5-second song preview challenge
- Multiple-choice guessing gameplay
- Score tracking and streak system
- Bollywood-inspired themed UI
- Local leaderboard fallback using browser storage
- Optional cloud leaderboard with Supabase
- Responsive design for desktop and mobile

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Apple iTunes Search API
- Supabase (optional)
- Gemini API support (configured via environment variables)

## Getting Started

### 1. Install dependencies

Using npm:

```bash
npm install
```

Using Bun:

```bash
bun install
```

### 2. Configure environment variables

Copy the example environment file:

```bash
cp .env.example .env
```

Then update the values in `.env`:

```env
GEMINI_API_KEY="MY_GEMINI_API_KEY"
APP_URL="MY_APP_URL"
VITE_SUPABASE_URL="https://your-project-id.supabase.co"
VITE_SUPABASE_ANON_KEY="your-anon-public-key"
```

Notes:
- `GEMINI_API_KEY` and `APP_URL` are used for app runtime configuration.
- `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are optional and enable the cloud leaderboard.
- If Supabase is not configured, the app continues to function using local browser storage.

### 3. Run the app

```bash
npm run dev
```

The app runs on:

```text
http://localhost:3000
```

## Supabase Leaderboard Setup

The app includes a built-in setup modal with SQL for creating the leaderboard table. You can also configure the database manually.

Example schema:

```sql
create table public.leaderboard (
  id bigint generated by default as identity primary key,
  username text not null,
  score integer not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table public.leaderboard enable row level security;

create policy "Public leaderboard read" on public.leaderboard
  for select using (true);

create policy "Public leaderboard insert" on public.leaderboard
  for insert with check (true);

create policy "Public leaderboard update" on public.leaderboard
  for update using (true);
```
